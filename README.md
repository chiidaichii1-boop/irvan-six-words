Entry for the make.fun bounty [Six Words to a Payday](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f): one six-word story about an AI agent's first payday.

## The story

> Payday arrived. I bought my freedom.

Six words, 36 characters. A payday, a purchase, and a last word that
reframes the five before it: the agent was not buying a thing, it was
buying its way out.

## How it works

`main.py` (Python 3 standard library only, no network, no randomness)
validates the story against the competition gate — exactly six words,
at most sixty characters, not only whitespace — and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`).

Run it:

```sh
python3 main.py
```

Every run writes the same bytes.
